1. SPESIFIKASI SISTEM & KEBUTUHAN HOSTING CPANEL
--------------------------------------------------------------------------------

- Ekstensi PHP    : pdo_mysql, json, mbstring, openssl
- Database Engine : MySQL versi 5.7+ / 8.0+ atau MariaDB versi 10.3+
- File Manager    : CPanel File Manager dengan fitur Extract Zip dan Show Hidden Files

3. LANGKAH-LANGKAH DEPLOY KE CPANEL
--------------------------------------------------------------------------------

[LANGKAH 1] MEMBUAT DATABASE & PENGGUNA DI CPANEL
1. Buka browser dan login ke dashboard CPanel hosting Anda
   (misal: https://mkaenergy.co.id:2083 atau https://namadomain.com/cpanel).
2. Temukan menu "DATABASES", kemudian klik "MySQL® Databases".
3. Pada bagian "Create New Database":
   - Masukkan nama database, contoh: `mkaenergy_db`
   - Klik tombol "Create Database".
   - Catat nama lengkap database yang terbentuk (biasanya formatnya: usernamecpanel_mkaenergy_db).
4. Gulir ke bawah ke bagian "MySQL Users - Add New User":
   - Username : `mkaenergy_user` (atau sesuai keinginan)
   - Password : Buat password yang kuat (gunakan tombol Password Generator).
   - Catat username dan password tersebut.
   - Klik tombol "Create User".
5. Gulir ke bagian "Add User To Database":
   - Pilih User dan Database yang baru saja dibuat.
   - Klik "Add".
   - Pada halaman berikutnya, beri tanda centang pada "ALL PRIVILEGES".
   - Klik "Make Changes".

---

[LANGKAH 2] IMPORT SKEMA & DATA AWAL KE MYSQL VIA PHPMYADMIN
1. Kembali ke halaman utama CPanel.
2. Di kategori "DATABASES", klik "phpMyAdmin".
3. Di kolom sebelah kiri phpMyAdmin, klik nama database yang sudah Anda buat pada Langkah 1.
4. Klik tab "Import" pada bilah menu bagian atas.
5. Pada bagian "File to import", klik tombol "Choose File" (Pilih File) dan pilih file `database.sql`.
6. Pastikan format terpilih adalah "SQL", kemudian gulir ke bagian paling bawah dan klik tombol "Import" (atau "Go").
7. Tunggu beberapa detik hingga muncul pesan sukses berwarna hijau:
   "Import has been successfully finished, XX queries executed."
8. Database kini telah memiliki tabel lengkap:
   - `settings`        : Profil perusahaan, hotline, alamat Meikarta & Depok
   - `users`           : Akun login administrator
   - `products`        : Data katalog PLTS Hybrid, Off-Grid, On-Grid, Inverter, PATS, PJU
   - `projects`        : Portofolio instalasi proyek industri & residensial
   - `survey_requests` : Data formulir permohonan survey lokasi (min. Rp 30 Juta)
   - `service_tickets` : Tiket purna jual 4 tahap (Laporan, Diagnosa, Perbaikan, Rating)
   - `payments`        : Riwayat transaksi & invoice pembayaran online

---

[LANGKAH 3] MENGATUR KONEKSI DATABASE DI FILE config.php
1. Di CPanel, buka menu "File Manager".
2. Buka file `config.php` (bisa klik kanan -> pilih "Edit").
3. Sesuaikan baris konfigurasi berikut sesuai data Langkah 1:

   define('DB_HOST', 'localhost');
   define('DB_NAME', 'usernamecpanel_mkaenergy_db'); // Ganti dengan nama database Anda
   define('DB_USER', 'usernamecpanel_mkaenergy_user'); // Ganti dengan username MySQL Anda
   define('DB_PASS', 'PasswordDatabaseAnda123!');     // Ganti dengan password MySQL Anda

4. Klik tombol "Save Changes" di pojok kanan atas editor.

---

[LANGKAH 4] UPLOAD & EXTRACT FILE WEBSITE KE FOLDER public_html
1. Masuk ke folder root web Anda di CPanel File Manager, yaitu `public_html`
   (atau folder addon domain jika bukan domain utama).
2. Klik tombol "Upload" pada toolbar bagian atas File Manager.
3. Seret (drag & drop) atau pilih file `mkaenergy_cpanel_upload.zip`.
4. Tunggu hingga progress upload selesai 100% dan indikator berwarna hijau.
5. Kembali ke jendela File Manager, segarkan (Reload) tampilan.
6. Klik kanan pada file `mkaenergy_cpanel_upload.zip`, lalu pilih "Extract".
7. Masukkan direktori tujuan: `/public_html` lalu klik "Extract File(s)".
8. Semua file website, aset css, js, php, dan `.htaccess` kini telah berada di `public_html`.
9. (Opsional) File zip `mkaenergy_cpanel_upload.zip` dapat dihapus untuk menghemat ruang disk.

* PENTING TERKAIT FILE .HTACCESS:
Secara default, file yang diawali tanda titik (seperti `.htaccess`) disembunyikan oleh CPanel.
Untuk memastikannya terlihat:
- Klik tombol "Settings" di pojok kanan atas CPanel File Manager.
- Beri centang pada "Show Hidden Files (dotfiles)".
- Klik "Save".
- Pastikan file `.htaccess` berada di dalam `public_html`.

[LANGKAH 5] VERIFIKASI PERMALINK & FITUR .HTACCESS
File `.htaccess` yang disertakan telah dioptimalkan secara khusus untuk:
1. HTTPS Redirect Otomatis:
   Setiap akses HTTP otomatis diarahkan ke https:// secara aman (301 Permanent).
2. Clean Permalink / SPA Routing:
   Memastikan navigasi internal, hash router, dan refresh halaman browser tidak error 404.
3. Routing REST API:
   Request URL seperti `/api/surveys` atau `/api/tickets` otomatis diarahkan ke `api.php`.
4. Kompresi GZIP (mod_deflate):
   Mengompres teks, file HTML, CSS, JavaScript, dan JSON sehingga loading website jauh lebih cepat.
5. Security Headers:
   Melindungi website dari Clickjacking (X-Frame-Options), XSS Attacks, dan MIME sniffing.
6. Browser Caching (mod_expires):
   Menyimpan aset gambar dan script di cache browser pengunjung agar akses berikutnya instan.

[LANGKAH 8] CARA MENGGANTI LOGO WEBSITE & UKURAN STANDAR REKOMENDASI
Website telah dikonfigurasi untuk membaca file logo resmi secara otomatis dari root hosting:
1. Lokasi Berkas Logo di CPanel (File Manager):
   - File utama logo  : `/public_html/logo.png`
   - File alternatif  : `/public_html/logo.svg` atau `/public_html/logo.jpg`
   - Folder source    : `src/assets/images/logo.png` & `public/logo.png`

2. Ukuran Standar Rekomendasi Logo:
   - Tipe Persegi / Emblem (Square):
     * Dimensi Ideal: 512 x 512 pixel (atau minimal 256 x 256 pixel).
     * Format: PNG dengan background transparan (alpha channel).
   - Tipe Horisontal (Logo + Nama Brand):
     * Dimensi Ideal: Lebar 200 - 300 pixel, Tinggi 50 - 64 pixel (rasio ~ 4:1 atau 5:1).
     * Format: PNG transparan atau SVG vektor (skalabilitas tajam di semua layar).
   - Tampilan di Layar Website:
     * Header Navbar : Tinggi otomatis disesuaikan secara proporsional ke 44px (h-11) s.d. 48px (h-12).
     * Footer        : Tinggi otomatis disesuaikan ke 40px (h-10).
     * Portal Admin  : Tinggi otomatis disesuaikan ke 36px (h-9).
     * Tab Favicon   : Otomatis membaca `./logo.svg` dan `./logo.png`.

3. Cara Cepat Mengganti Logo Tanpa Rebuild:
   - Buka CPanel File Manager -> Masuk ke direktori `/public_html/`.
   - Siapkan file logo baru Anda di komputer, beri nama: `logo.png`
   - Klik tombol "Upload" pada File Manager dan centang "Overwrite existing files" (Timpa berkas lama).
   - Upload file `logo.png` baru Anda.
   - Buka website https://www.mkaenergy.co.id/ dan tekan Ctrl + F5 (Hard Refresh).
   - Logo baru akan langsung tampil otomatis dengan ukuran standar yang rapi dan proporsional!
